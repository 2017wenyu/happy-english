### 问题
听写默写页面（chinese_dictation）点击「重复播报」没有声音。

### 原因分析

### 修复方案
- `chinese_dictation.js`：改为 `wx.getStorageSync('soundEnabled') !== false`
- `utils/audio.js`：改为 `wx.getStorageSync('soundEnabled') !== false`
- `utils/voice.js`：改为 `wx.getStorageSync('soundEnabled') !== false`

### 逻辑说明
- 默认开启音效（storage 无值或值为 true 都播放）
- 只有当用户明确关闭（设为 false）时才不播放
- 与 profile 页面的音效开关逻辑保持一致

## 古诗错题功能优化（2026-04-07 23:57）

### 问题
用户反馈古诗词里面有几个地方做错了或者答错了都没有计入错题本。

### 排查结果
所有古诗页面都有 `recordMistake()` 方法，但调用时机不同：

| 页面 | 错题触发时机 | 状态 |
|------|-------------|------|
| poem_read（跟读） | 手动点击"暂存"按钮 | ✅ 正常 |
| poem_chain（接龙） | 接龙失败时自动记录 | ✅ 正常 |
| poem_write（默写） | 填空/全篇错误时记录 | ✅ 正常 |
| poem_guess（猜诗） | 猜错时记录 | ✅ 正常 |
| poem_puzzle（拼图） | 拼接错误时记录 + 手动"暂存" | ✅ 正常 |

### 优化内容
1. **poem_read.wxss**：添加"暂存到错题本"按钮样式（红色系 #FF4D4F）
2. **mistakes.wxml**：已支持古诗错题列表显示（标题、作者、朝代、诗句内容）
